# Guia para Estudantes de Programação

## Sobre o projeto

Este projeto foi desenvolvido como atividade da disciplina de HTML, com o objetivo de criar um site educativo voltado para estudantes que estão iniciando seus estudos em programação.

O site apresenta informações introdutórias sobre linguagens de programação, conceitos fundamentais, ferramentas utilizadas no desenvolvimento de software e recursos que podem auxiliar nos estudos.

O projeto foi desenvolvido utilizando HTML, com foco na utilização de elementos semânticos e diferentes recursos oferecidos pela linguagem.

## Páginas

### Início

Apresenta o objetivo do guia, algumas áreas da programação, os primeiros passos para quem está começando e uma trilha básica de aprendizagem.

### Linguagens

Apresenta algumas linguagens de programação, como Python, C, C++, Java e JavaScript, abordando suas características e algumas de suas aplicações.

### Conceitos

Explica conceitos fundamentais da programação, como variáveis, estruturas condicionais, estruturas de repetição, funções, listas, orientação a objetos e APIs.

### Ferramentas

Apresenta algumas ferramentas utilizadas por programadores, como Visual Studio Code, Git, GitHub, terminal, navegador e documentação.

### Recursos

Reúne informações sobre formas de estudar programação, incluindo documentação, exercícios, projetos e organização dos estudos. A página também apresenta um formulário relacionado aos estudos de programação.

## Navegação

Todas as páginas possuem um menu de navegação para facilitar o acesso às diferentes partes do site:

* Início
* Linguagens
* Conceitos
* Ferramentas
* Recursos
